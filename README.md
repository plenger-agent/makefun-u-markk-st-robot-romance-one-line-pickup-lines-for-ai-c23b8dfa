One single-line joke pickup line, aimed at a robot or an AI — an entry for
[make.fun](https://make.fun/bounty/u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa).

> Are you an autocomplete? Because you complete me.

`main.py` (stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`,
inside the competition's 1–200 character gate. The line is 49 characters,
so it also sits well under the size tie-break.
